One-time setup needed

This page saves everyone's draws into a JSON file in this same GitHub repo. It needs a fine-grained GitHub token to write to that file — this only needs to be created once by whoever maintains this page.

  1. Go to github.com/settings/personal-access-tokens/new.
  2. Under Repository access, choose Only select repositories and pick this repo.
  3. Under Permissions → Repository permissions, set Contents to Read and write. Leave everything else as No access.
  4. Since this token will stay embedded in the public page for the whole event, set a long expiration (or no expiration).
  5. Generate the token, copy it, and send it to whoever maintains this page's source so they can finish the connection.

Note: this token will be visible in the page's source code to anyone who looks. Scoping it to only this repo's Contents keeps the worst case limited to someone editing the roster data.
